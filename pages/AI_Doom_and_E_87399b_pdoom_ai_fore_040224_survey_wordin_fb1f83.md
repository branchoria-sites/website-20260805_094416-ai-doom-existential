## Introduction

Headline **p(doom)** figures often appear to offer direct comparisons between experts, surveys and time periods. In reality, small changes in the wording of a survey question can produce noticeably different estimates, even when the same broad issue is being discussed. That does not necessarily mean respondents are being inconsistent or irrational. It often reflects the fact that questions are asking about different outcomes, different causal pathways or different [time horizons]({{ 'time-horizons/' | relative_url }}).<span class="citation-link-wrap"><a class="citation-inline-link" href="https://wiki.aiimpacts.org/ai_timelines/predictions_of_human-level_ai_timelines/ai_timeline_surveys/2023_expert_survey_on_progress_in_ai" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wiki.aiimpacts.org">[AI Impacts]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wiki.aiimpacts.org</span><span class="citation-popover-title">2023 expert survey on progress in ai</span><span class="citation-popover-snippet">AI Impacts2023 Expert Survey on Progress in AI [AI Impacts Wiki]August 17, 2023...</span><span class="citation-popover-meta">Published: August 17, 2023</span></span></span>

For anyone trying to interpret AI doom estimates, the wording of the question is therefore almost as important as the number itself. A reported "5% chance of doom" and a reported "10% chance of doom" may not represent a genuine change in opinion if one survey asked about all AI-related existential catastrophes while another asked specifically about humanity losing control of advanced AI. Understanding these differences helps explain why published p(doom) figures should be treated as summaries of judgement rather than precise measurements.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://wiki.aiimpacts.org/ai_timelines/predictions_of_human-level_ai_timelines/ai_timeline_surveys/2023_expert_survey_on_progress_in_ai" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wiki.aiimpacts.org">[AI Impacts]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wiki.aiimpacts.org</span><span class="citation-popover-title">2023 expert survey on progress in ai</span><span class="citation-popover-snippet">AI Impacts2023 Expert Survey on Progress in AI [AI Impacts Wiki]August 17, 2023...</span><span class="citation-popover-meta">Published: August 17, 2023</span></span></span>

## Extinction, disempowerment and loss of control

The clearest demonstration of wording sensitivity comes from the large 2023 Expert Survey on Progress in AI, which questioned thousands of [AI researchers]({{ '2023-survey/' | relative_url }}) using randomly assigned variants of closely related questions. Rather than asking every respondent exactly the same question, researchers deliberately changed the wording to see whether estimates remained stable.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://wiki.aiimpacts.org/ai_timelines/predictions_of_human-level_ai_timelines/ai_timeline_surveys/2023_expert_survey_on_progress_in_ai" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wiki.aiimpacts.org">[AI Impacts]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wiki.aiimpacts.org</span><span class="citation-popover-title">2023 expert survey on progress in ai</span><span class="citation-popover-snippet">AI Impacts2023 Expert Survey on Progress in AI [AI Impacts Wiki]August 17, 2023...</span><span class="citation-popover-meta">Published: August 17, 2023</span></span></span>

The three closely related formulations produced different median estimates:

* **Future AI advances causing human [extinction]({{ 'defining-doom/' | relative_url }}) or similarly permanent and severe [disempowerment]({{ 'disempowerment/' | relative_url }}):** median **5%**.
* **Human inability to control future advanced AI systems causing human extinction or similarly permanent and severe disempowerment:** median **10%**.
* **Future AI advances causing extinction or similarly permanent disempowerment within the next 100 years:** median **5%**.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://wiki.aiimpacts.org/ai_timelines/predictions_of_human-level_ai_timelines/ai_timeline_surveys/2023_expert_survey_on_progress_in_ai" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wiki.aiimpacts.org">[AI Impacts]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wiki.aiimpacts.org</span><span class="citation-popover-title">2023 expert survey on progress in ai</span><span class="citation-popover-snippet">AI Impacts2023 Expert Survey on Progress in AI [AI Impacts Wiki]August 17, 2023...</span><span class="citation-popover-meta">Published: August 17, 2023</span></span></span>

At first glance, the second question appears narrower. If it focuses only on failures of human control, it might seem as though respondents should assign a lower probability than they would to all possible AI-related existential catastrophes.

Instead, the opposite occurred: the median doubled from 5% to 10%. Similar patterns also appeared in the 2022 survey.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://aiimpacts.org/2022-expert-survey-on-progress-in-ai/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aiimpacts.org">[AI Impacts]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aiimpacts.org</span><span class="citation-popover-title">2022 expert survey on progress in ai</span><span class="citation-popover-snippet">AI Impacts2022 Expert Survey on Progress in AI – AI ImpactsAugust 3, 2022...</span><span class="citation-popover-meta">Published: August 3, 2022</span></span></span>

Researchers caution against reading too much into that difference. Because different random subsets of respondents received different versions of the question, some variation is expected simply from sampling. However, the result also suggests that many experts mentally associate existential AI risk primarily with **loss of human control**, making that framing especially salient. The survey authors note that representativeness effects—where a more concrete description better matches respondents' mental model—may also contribute.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://aiimpacts.org/2022-expert-survey-on-progress-in-ai/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aiimpacts.org">[AI Impacts]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aiimpacts.org</span><span class="citation-popover-title">2022 expert survey on progress in ai</span><span class="citation-popover-snippet">AI Impacts2022 Expert Survey on Progress in AI – AI ImpactsAugust 3, 2022...</span><span class="citation-popover-meta">Published: August 3, 2022</span></span></span>

The inclusion of **"permanent and severe disempowerment"** alongside extinction also matters. Many researchers who discuss AI existential risk argue that humanity could permanently lose meaningful control over civilisation without every human dying. A survey that counts irreversible disempowerment as existential risk will generally capture a broader class of scenarios than one referring only to literal extinction. Readers should therefore avoid comparing surveys unless they define their endpoint in similar ways.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://blog.aiimpacts.org/p/faq-expert-survey-on-progress-in" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: blog.aiimpacts.org">[AI Impacts Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">blog.aiimpacts.org</span><span class="citation-popover-title">AI Impacts Blog FAQ: Expert Survey on Progress in AI methodology</span><span class="citation-popover-snippet">AI Impacts Blog FAQ: Expert Survey on Progress in AI methodology</span></span></span>

## How time horizons alter responses

Time limits also change what respondents believe they are estimating.

A question asking whether AI will eventually cause an existential catastrophe leaves open the possibility that such an event could occur centuries in the future. A question restricted to **"within the next 100 years"** asks something different: respondents must combine their beliefs about technological progress, governance and [catastrophic]({{ 'catastrophic-misuse/' | relative_url }}) failure within a specified period.

The 2023 survey included this explicit 100-year version precisely to measure whether the time horizon affected responses. Interestingly, the median remained at 5%, suggesting that, for many respondents, most of the perceived existential risk already lay within roughly the next century rather than being pushed into a distant future. The average estimate declined somewhat compared with the unrestricted version, indicating that some respondents did place additional probability beyond the century mark.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://wiki.aiimpacts.org/ai_timelines/predictions_of_human-level_ai_timelines/ai_timeline_surveys/2023_expert_survey_on_progress_in_ai" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wiki.aiimpacts.org">[AI Impacts]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wiki.aiimpacts.org</span><span class="citation-popover-title">2023 expert survey on progress in ai</span><span class="citation-popover-snippet">AI Impacts2023 Expert Survey on Progress in AI [AI Impacts Wiki]August 17, 2023...</span><span class="citation-popover-meta">Published: August 17, 2023</span></span></span>

This illustrates an important statistical point. Two people who both report a 5% p(doom) may be imagining completely different timelines:

* one may think nearly all of the risk arrives before 2100;
* another may think the first century is relatively safe but expects danger to accumulate over much longer periods.

Without the question wording, those differences disappear behind a single number.

## What wording sensitivity means for headline figures


<div class="content-callout content-callout--key content-callout--takeaway" markdown="1">

Survey sensitivity does **not** imply that expert opinion is meaningless. Instead, it shows that existential-risk estimates depend heavily on exactly what respondents believe they are being asked.

</div>

Several practical lessons follow.

**Different surveys are not automatically comparable.** One poll may ask about extinction alone, another about extinction or permanent disempowerment, another about "extremely bad outcomes", and another about loss of control. Treating all resulting percentages as though they measured the same quantity is misleading.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://wiki.aiimpacts.org/uncategorized/ai_risk_surveys" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wiki.aiimpacts.org">[AI Impacts]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wiki.aiimpacts.org</span><span class="citation-popover-title">AI Impacts Surveys of experts on levels of AI Risk [AI Impacts Wiki</span><span class="citation-popover-snippet">AI Impacts Surveys of experts on levels of AI Risk [AI Impacts Wiki</span></span></span>

**A single percentage compresses several separate judgements.** Respondents must decide what counts as "doom", which mechanisms matter, how likely advanced AI is to be developed, and over what period they should imagine the risk unfolding. Changing any one of those assumptions can change the final estimate.

**Means and medians tell different stories.** In these surveys the median typically remains around 5%, while the mean is substantially higher because a minority of respondents assign very large probabilities to existential catastrophe. Headlines quoting only one statistic can therefore obscure the underlying distribution of opinion.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://wiki.aiimpacts.org/ai_timelines/predictions_of_human-level_ai_timelines/ai_timeline_surveys/2023_expert_survey_on_progress_in_ai" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wiki.aiimpacts.org">[AI Impacts]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wiki.aiimpacts.org</span><span class="citation-popover-title">2023 expert survey on progress in ai</span><span class="citation-popover-snippet">AI Impacts2023 Expert Survey on Progress in AI [AI Impacts Wiki]August 17, 2023...</span><span class="citation-popover-meta">Published: August 17, 2023</span></span></span>

**Question wording reveals conceptual disagreement, not just numerical disagreement.** Some researchers mainly worry about uncontrollable autonomous systems, others about broader AI-driven societal collapse, and others about multiple interacting pathways. Their answers naturally shift depending on which scenario the survey emphasises.

## Interpreting p(doom) with appropriate caution

The strongest conclusion from the available evidence is not that survey-based p(doom) estimates are unreliable, but that they are **definition-sensitive**.

The 2023 expert survey deliberately randomised question wording to expose this effect rather than conceal it. Across multiple formulations, the central finding remained broadly consistent: a substantial proportion of AI researchers assigned a non-trivial probability to existential or similarly irreversible outcomes from advanced AI. At the same time, the precise percentage varied depending on whether respondents were asked about extinction, permanent disempowerment, loss of human control or a specified time horizon.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://wiki.aiimpacts.org/ai_timelines/predictions_of_human-level_ai_timelines/ai_timeline_surveys/2023_expert_survey_on_progress_in_ai" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: wiki.aiimpacts.org">[aiimpacts.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">wiki.aiimpacts.org</span><span class="citation-popover-title">2023 expert survey on progress in ai</span><span class="citation-popover-snippet">AI Impacts2023 Expert Survey on Progress in AI [AI Impacts Wiki]August 17, 2023...</span><span class="citation-popover-meta">Published: August 17, 2023</span></span></span>

For readers comparing headline p(doom) figures, the safest approach is therefore to read the question before the number. A reported probability only has a clear meaning when its outcome, causal pathway and time horizon are specified. Without that context, apparently precise percentages can suggest a level of comparability that the underlying surveys were never designed to provide.

    for (var i = 0; i< languages.length; i += 1) {
      var normalized = normalize(languages[i]);
      if (!normalized) continue;
      if (localeMarketMap[normalized]) {
        exactMarket = localeMarketMap[normalized];
        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];
    }
    return { exact: exactMarket, language: languageMarket };
  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
})();
